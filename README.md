# Dashboard Keuangan Mini

## Tentang Proyek
Dashboard Keuangan Mini adalah proyek belajar Data Analysis menggunakan Google Sheets untuk mencatat dan menganalisis pengeluaran pribadi.

## Tujuan
- Mempelajari pengolahan data menggunakan Google Sheets.
- Membuat Pivot Table untuk merangkum pengeluaran berdasarkan kategori.
- Menampilkan data melalui grafik.
- Mengambil insight berdasarkan hasil analisis.

## Tools yang Digunakan
- Google Sheets
- GitHub

## Hasil Proyek
- Tabel catatan pengeluaran.
- Conditional Formatting.
- Pivot Table per kategori.
- Grafik batang pengeluaran.
- Tiga insight dari data pengeluaran.
- Praktik data cleaning menggunakan TRIM, SPLIT, dan fitur hapus duplikat.

## Data
Proyek ini menggunakan data latihan yang terdiri dari lima transaksi pengeluaran.
